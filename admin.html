여기서 올린 이미지·글은 GitHub 저장소에 그대로 저장되고, 마인드맵의 골라준 위치 아래에 자동으로 추가됩니다. 관리자 전용 페이지이며, archive.md는 호수·유형처럼 고정된 형식이 아니어도 되므로 아래에서 원하는 이름으로 자유롭게 항목을 만들 수 있습니다.

GitHub 토큰은 어떻게 만드나요?

GitHub 우측 상단 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
Repository access는 Only select repositories로 하고 이 저장소만 선택하세요.
Permissions → Repository permissions → Contents: Read and write로 설정하고 생성하면 됩니다.
생성된 토큰을 아래에 붙여넣으세요. 이 토큰은 이 브라우저에만 저장되고 서버로 전송되지 않습니다(GitHub API로 직접 전송).
