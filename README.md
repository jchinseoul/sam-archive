# 문학회 매거진 아카이브 — 유지보수 가이드

이 저장소는 동아리 매거진 아카이브를 마인드맵 형태로 보여주는 웹사이트입니다.
**앞으로 여러분이 수정할 파일은 `archive.md` 하나뿐입니다.** `index.html`, `app.js`, `style.css`는 다시 건드릴 필요가 없습니다.

## 사이트 주소

GitHub Pages 설정 후 `https://<사용자이름>.github.io/<저장소이름>/` 형태의 주소가 생깁니다.

## `archive.md` 수정하는 법 (터미널/git 명령 필요 없음)

1. GitHub 저장소 페이지에서 `archive.md` 클릭
2. 오른쪽 위 연필(✏️) 아이콘 클릭 → 편집 모드 진입
3. 아래 템플릿을 참고해서 줄을 추가/수정
4. 아래로 스크롤 → `Commit changes...` 클릭 → `Commit directly to the main branch` 선택 → 커밋
5. 1분 정도 기다린 후 사이트 새로고침하면 반영됨

### 규칙
- 들여쓰기 **2칸 = 한 단계 더 깊은 가지**입니다. 탭 대신 스페이스 2칸을 사용하세요.
- 순서: `호수` → `유형` → `개별 게시물`
- 유형은 4가지로 통일합니다: 📢 공지 / ✍️ 투고작 / 🎤 행사 / 🗂 기타

### 새 호수를 통째로 추가할 때 (이 블록을 복사해서 맨 아래 붙여넣기)

```markdown
- 🌱 2026 봄호
  - 📢 공지
    - [공지 제목](인스타그램_게시물_링크)
  - ✍️ 투고작
    - [시 - "제목" (필명)](인스타그램_게시물_링크)
  - 🎤 행사
    - [행사 후기 제목](인스타그램_게시물_링크)
  - 🗂 기타
    - [기타 게시물 제목](인스타그램_게시물_링크)
```

### 기존 호수에 게시물 한 줄만 추가할 때

해당 호수의 해당 유형(예: `✍️ 투고작`) 아래에 아래 줄만 같은 들여쓰기로 추가하면 됩니다.

```markdown
    - [시 - "제목" (필명)](인스타그램_게시물_링크)
```

## 사이트가 이상하게 보일 때 확인할 것

- 들여쓰기가 스페이스 2칸 단위로 일관되게 되어 있는지 확인 (탭이 섞이면 구조가 깨질 수 있습니다)
- 대괄호/괄호 짝이 맞는지 확인: `[제목](링크)`
- 커밋 후 1~2분 정도 기다렸다가 새로고침 (강력 새로고침: Cmd+Shift+R / Ctrl+Shift+R)
