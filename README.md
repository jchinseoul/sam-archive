# SAM ARCHIVE — 동아리 매거진 마인드맵 아카이브

문학회 매거진 활동 기록을 인스타그램 피드에 묻히지 않게, **마인드맵 형태의 웹사이트**로 보여주는 저장소입니다.
`SAM ARCHIVE`라는 글자를 중심으로 사방(위·아래·좌·우)으로 가지가 뻗어나가며, 클릭할 때마다 한 단계씩 펼쳐집니다.

- **사이트 주소**: `https://<사용자이름>.github.io/<저장소이름>/` (GitHub Pages 설정 후 생성됨)
- **관리자**: 혼자 운영, 부원 인증 없이 링크만 알면 누구나 볼 수 있음

## 콘텐츠를 추가하는 두 가지 방법

### 방법 1 — `/admin.html` (이미지·영상·문서·글 직접 업로드, 추천)

인스타그램 링크 없이 **이미지·영상·문서 파일이나 직접 쓴 글을 바로 올릴 수 있는 관리자 전용 페이지**입니다.

1. 사이트 주소 뒤에 `/admin.html`을 붙여서 접속 (예: `https://사용자이름.github.io/저장소이름/admin.html`)
2. 최초 1회만 GitHub 개인 액세스 토큰 입력 (아래 "토큰 만드는 법" 참고) — 이후엔 이 브라우저에 저장되어 다시 안 넣어도 됨. 항목이 안 불러와지면 "항목 새로고침" 버튼을 눌러보세요.
3. 1단계 항목 선택(또는 새로 추가, 예: 호수·연도) → 2단계 항목 선택(또는 새로 추가, 예: 유형·계절) → 제목 입력 — 두 드롭다운 모두 지금 `archive.md`에 실제로 있는 항목만 보여줍니다
4. 아래 중 하나만 채우면 됨 (여러 개를 채우면 **영상 링크 → 영상 파일 → 문서 파일 → 이미지 → 글** 순서로 하나만 사용됨):
   - 이미지 파일
   - 문서 파일 — PDF, 한글(HWP/HWPX), Word(DOC/DOCX)
   - 영상 파일 — 용량이 작고 짧은 영상 권장. 15MB가 넘으면 경고만 뜨고 업로드는 그대로 진행됨(GitHub 저장소가 무거워질 수 있으니 참고)
   - 영상 링크 — 유튜브·인스타그램 등 이미 올라가 있는 영상 URL (용량 제한 없음, 저장소도 가벼움)
   - 글 내용 — 입력하면 텍스트 파일로 저장됨
   - 아무것도 안 넣으면 제목만 있는 항목이 됨
5. "올리기" 클릭 → 파일은 `assets/` 폴더에 저장되고(영상 링크는 파일 업로드 없이 URL만 저장), `archive.md`에도 알맞은 위치에 자동으로 한 줄이 추가됨
6. 1분 정도 후 사이트에 반영되며, 방금 글이 올라간 1단계·2단계 카테고리 글자 오른쪽 위에 **빨간 점**이 7일 동안 표시됨 (`updates.json`에 기록되고, `admin.html`이 자동으로 관리하므로 직접 손댈 필요 없음)

**토큰 만드는 법 (최초 1회만)**

1. GitHub 우측 상단 프로필 → **Settings** → 맨 아래 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. Repository access: **Only select repositories** → 이 저장소만 선택
4. Permissions → Repository permissions → **Contents: Read and write**
5. 생성된 토큰(`github_pat_...`)을 `/admin.html`에 붙여넣기

토큰은 이 브라우저에만 저장되고 서버로 전송되지 않습니다(깃허브 API로 직접 전송). 실제로 글을 올리려면 이 토큰이 있어야 하므로, 페이지 링크를 몰라도 사실상 관리자만 콘텐츠를 추가할 수 있습니다.

### 방법 2 — `archive.md` 직접 수정 (터미널/git 명령 필요 없음)

간단한 텍스트만 추가하고 싶을 때는 GitHub 웹 화면에서 직접 고쳐도 됩니다.

1. GitHub 저장소 페이지에서 `archive.md` 클릭
2. 오른쪽 위 연필(✏️) 아이콘 클릭 → 편집 모드 진입
3. 아래 규칙에 맞춰 줄을 추가/수정
4. 아래로 스크롤 → `Commit changes...` → `Commit directly to the main branch` → 커밋
5. 1분 정도 후 사이트 새로고침하면 반영됨

**규칙**

- 첫 줄 `# 제목`이 마인드맵 정중앙 글자가 됩니다 (현재: `SAM ARCHIVE`)
- 들여쓰기 **2칸 = 한 단계 더 깊은 가지**입니다. 탭 대신 스페이스 2칸을 사용하세요.
- 계층 깊이·구조에 제한은 없습니다. `호수 → 유형 → 개별 게시물`처럼 3단계로 정리해도 되고, 그냥 편하게 이름만 나열해도 됩니다.
- 링크를 걸고 싶으면 `[제목](경로 또는 URL)`, 그냥 글자만 두려면 `- 제목`처럼 링크 없이 써도 됩니다.

지금 실제 `archive.md`는 아래처럼 자유로운 형태로 섞여 있습니다 (일부만 발췌):

```markdown
# SAM ARCHIVE

- 시집 추천
  - 봄
  - 여름
  - 가을
  - 겨울
- 2026
  - 신입부원 모집
  - 7월
    - 공지사항
    - 장마
    - 방학
  - 8월
    - 공지사항
```

정식으로 "호수 → 유형 → 게시물" 형태를 갖추고 싶다면 아래 템플릿처럼 쓰고, 이미지·원본 게시물 링크는 `/admin.html`로 올리거나 `[제목](경로 또는 URL)` 형식으로 직접 적으면 됩니다.

기존 호수에 게시물 한 줄만 추가할 때는, 해당 유형(또는 상위 항목) 아래에 같은 들여쓰기로 한 줄만 추가하면 됩니다.

## 사이트 사용법 (방문자 기준)

- 글자를 클릭하면 그 아래 가지가 펼쳐지고, 다시 클릭하면 접힙니다.
- 링크가 있는 게시물(리프)을 클릭하면 이미지/글/원본 게시물이 새 탭에서 열립니다.
- 우측 상단 **화면에 맞추기**: 흩어진 마인드맵을 다시 화면 중앙에 맞춰줍니다.
- 우측 상단 **리스트로 보기**: 마인드맵 조작이 불편할 때(주로 모바일) 같은 내용을 접이식 목록으로 봅니다.
- 가지 길이는 무작위가 아니라, **해당 카테고리에 콘텐츠가 많을수록 짧게** 표시됩니다(중심과 더 강하게 연결된 것으로 간주). 여기에 자연스러운 손그림 느낌을 위한 약간의 흔들림이 더해집니다.
- 글씨 크기는 중심(36px) → 1단계 호수(20px) → 그 아래 전부(16px) 순으로 작아집니다.
- 최근 7일 안에 새 게시물이 올라온 카테고리는 글자 오른쪽 위에 **빨간 점**이 표시됩니다.

## 파일 구조

| 파일                                  | 역할                                         | 다시 건드릴 일                   |
| ------------------------------------- | -------------------------------------------- | -------------------------------- |
| `archive.md`                          | 실제 콘텐츠 데이터 (호수/유형/게시물)        | **이 파일만 계속 수정**          |
| `admin.html` / `admin.js`             | 관리자 업로드 도구                           | 보통 건드릴 필요 없음            |
| `index.html` / `app.js` / `style.css` | 마인드맵 렌더링 로직                         | 다시 건드릴 필요 없음            |
| `assets/`                             | 업로드한 이미지·영상·문서·글 텍스트 파일이 쌓이는 폴더 | 직접 관리 안 해도 됨 (자동 생성) |
| `updates.json`                        | "최근 업데이트됨" 빨간 점 표시용 기록        | 직접 관리 안 해도 됨 (자동 생성/정리) |

## 사이트가 이상하게 보일 때 확인할 것

- `archive.md`의 들여쓰기가 스페이스 2칸 단위로 일관되게 되어 있는지 확인 (탭이 섞이면 구조가 깨질 수 있습니다)
- 대괄호/괄호 짝이 맞는지 확인: `[제목](링크)`
- 커밋/업로드 후 1~2분 정도 기다렸다가 새로고침 (강력 새로고침: Cmd+Shift+R / Ctrl+Shift+R)
- `admin.html`에서 오류가 나면 토큰의 저장소 선택과 Contents 권한(Read and write)이 맞는지 확인
